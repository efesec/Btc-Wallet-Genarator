# 🟠 Bitcoin Wallet Generator

A secure Python tool to generate Bitcoin wallets using BIP-39 mnemonics and BIP-44 derivation paths.

## 🚀 How to Run
1. **Install Dependencies:** `pip install -r requirements.txt`
2. **Execute Script:** `python btc.py`
3. **Input:** Enter the number of wallets you wish to generate when prompted.

## 🛠 Technical Specifications
| Feature | Value |
| :--- | :--- |
| **Derivation Path** | `m/44'/0'/0'/0/0` |
| **Address Type** | Legacy (P2PKH) |
| **Output File** | `btcwallet.txt` |
